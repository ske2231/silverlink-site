# SilverLink — Realtor Video Walkthroughs

Marketing site for SilverLink's realtor video-walkthrough service (Oklahoma City, OK).

- **Framework:** Astro 4 (static output)
- **Hosting:** Vercel — deploys automatically from `main`
- **Contact:** mk@silverlinkok.com · (405) 877-2223

## Develop

```bash
npm install
npm run dev      # local preview
npm run build    # production build -> dist/
```

The booking form opens a pre-addressed email (`mailto:`) — no backend.
